Divya & Akhil wedding invitation website

Publish on Render:
1. Create a new GitHub repository and add index.html at its root.
2. In Render choose New > Static Site and connect the repository.
3. Use Build command: echo ready
4. Use Publish directory: .
5. Select the Free plan, check name availability, then deploy.
6. After deployment opens, share its onrender.com URL.

This public bundle intentionally excludes the uploaded commercial movie soundtrack. A license or suitable authorised embed is needed before including that music on a public website.

RSVP uses mailto and opens the guest email app; it does not record submissions itself. Guests must send the drafted email.
